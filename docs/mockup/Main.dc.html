1Tải file mẫuFile .docx hoặc .xlsx bạn đang dùng. Xử lý ngay trong trình duyệt, không gửi lên mạng.

4Kiểm tra và xuất fileSo sánh với file mẫu, báo những chỗ khác ngoài vị trí biến, rồi tải về.
