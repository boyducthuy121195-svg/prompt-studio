- Link xem và bấm thử: https://claude.ai/artifact/5ehYGPek22DsNPgTX2Buan (đăng nhập claude.ai).

- Quy tắc: **xong mỗi task phải cập nhật mockup** cho khớp với app thật, rồi đăng lại lên cùng link (xem AGENTS.md mục 8).
